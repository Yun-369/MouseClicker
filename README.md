# MouseClicker 鼠标连点器

适用于 Windows 10/11 x64 的鼠标自动化工具，提供连点、鼠标与键盘录制回放、基础宏和定时启动。

## 下载

从 [GitHub Releases](https://github.com/Yun-369/MouseClicker/releases/latest) 下载附件 **MouseClicker.exe**，双击运行。单文件版已内置 .NET 8 桌面运行时。

[直接下载本次发布的 EXE](https://github.com/Yun-369/MouseClicker/releases/download/win-x64-20261121/MouseClicker.exe) · [使用说明](./使用说明.txt) · [本版验收说明](./docs/验收说明.md)

## 快速开始

1. 打开「连点控制」，选择左键、中键或右键，设置间隔、位置模式和停止方式。
2. 先用少量次数测试。固定坐标模式可先用「测试一次」确认点位。
3. 点击「开始连点」或使用已应用的快捷键。默认快捷键是 **F8**，紧急停止是 **Ctrl+Shift+F12**。也可用窗口底部的「停止当前任务」。

## 功能

| 功能 | 说明 |
| --- | --- |
| 前台连点 | 跟随光标、固定点、顺序或随机多点。普通单击通过 Windows `SendInput` 成对提交按下和松开，支持设置次数和时长。 |
| 后台窗口 | 在设置页选定目标，对指定窗口执行连点或录制回放。后台模式通过窗口消息传递输入，目标窗口需要支持这种方式。 |
| 录制回放 | 录制鼠标和键盘操作，保存为 JSON。支持倍速、重复、暂停、继续、编辑和优化另存。 |
| 定时 | 在连点页「更多设置」和录制回放页分别设置延迟启动或指定本地时间启动，等待期间可停止。 |
| 基础宏 | 支持移动、单击、等待、有限循环、引用录制、键盘按键和文本输入。 |
| 设置与托盘 | 自定义键盘或鼠标侧键热键。关闭窗口会保存改动并隐藏到托盘，托盘菜单「退出」会保存设置并结束进程。 |

开机自启可在设置页按需启用。设置和录制库信息位于 `%LOCALAPPDATA%\MouseClicker`。
