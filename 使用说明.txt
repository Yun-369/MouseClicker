MouseClicker 使用说明

一、下载和运行

从仓库的 Releases 页面下载 MouseClicker.exe。适用系统为 Windows 10/11 x64，EXE 已内置 .NET 8 桌面运行时。登录有仓库权限的 GitHub 账号即可下载。

主界面顶部有五个页面：连点控制、录制回放、基础宏、运行日志、设置。默认窗口外框 500×380，最小 480×360。页面内容可以滚动，底部显示运行状态和「停止当前任务」。

二、连点、定时与停止

1. 在「连点控制」设置鼠标按键、间隔、位置和停止方式。固定点可以先用「准星取点」和「测试一次」确认点位。多点模式可设顺序或随机。
2. 「更多设置」包含点击动作、随机偏移、间隔上限和定时连点。定时支持延迟秒数和指定本地时间。等待期间可用「停止当前任务」取消。
3. 点击「开始连点」或按已应用的快捷键。默认 F8，紧急停止为 Ctrl+Shift+F12。运行时从界面底部也可以停止。

三、前台与后台

前台连点通过 Windows SendInput 发送系统鼠标输入，固定点会把桌面光标移动到该位置。
要使用后台，进入「设置」勾选「后台窗口」，点「选择当前前台窗口」，在倒计时内切到目标窗口并把光标放进它的客户区。后台「跟随光标」使用选窗时记下的窗口内点位，窗口挪动后会跟随它的位置。
后台连点和回放通过窗口消息发送输入，桌面光标保持在当前位置。游戏、使用原始输入的程序或权限不同的窗口可能无法接收。目标选择有效期为本次程序运行。

四、热键与设置保存

在「设置」点击「修改」，按下并松开键盘组合或鼠标侧键 1、2，Esc 可取消。点击「应用热键」才会让新组合生效。支持 F1–F12、鼠标侧键，以及 Ctrl 或 Alt 加字母、数字、空格的组合，可加 Shift。
「保存设置」可立即写入。点窗口右上角关闭会保存并隐藏到托盘。从托盘菜单选择「退出」会保存并完整结束进程；下次启动自动恢复设置，程序保持空闲。

五、录制、回放和宏

在「录制回放」点「开始录制」，完成操作后停止并选择保存位置。载入录制后可选倍速和轮数，再回放或定时回放。编辑及优化结果另存为新文件。要通过录制库统一管理，可在录制库中选择「添加文件」。
在「基础宏」新建或载入宏。填好动作后保存，回到主界面点「运行宏」。宏有存储路径后会自动保存已提交的修改。绑定前台窗口的宏使用客户区坐标，目标失焦、最小化或关闭时会中断。
