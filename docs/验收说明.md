# 单文件版验收说明

对应发布 [win-x64-20261121](https://github.com/Yun-369/MouseClicker/releases/tag/win-x64-20261121)，附件为 Windows x64 的 `MouseClicker.exe`，大小 **71,779,195 字节**。

| 项目 | 结果 |
| --- | --- |
| 成品启动 | 启动了实际交付的单文件，确认使用内置 .NET 运行时，主窗口正常响应，五个页面可进入。 |
| 前台定点连点 | 三次连点产生三组系统鼠标按下和松开，自有测试窗口收到三次左键点击。 |
| 完全退出保存 | 更改间隔后从托盘退出，进程以退出码 0 结束。重启读回测试值，随后恢复原设置。 |
| 后台输入与定时 | 后台键盘、鼠标回放和优化相关定向测试 43 项通过。定时复测 33 项通过、1 项跳过，跳过的是实际选窗步骤，后续用已知的自有窗口验证启动、取消和目标关闭。 |
| Release 构建 | 产品 0 警告、0 错误。测试工程有 2 条既有 CS1998 警告。 |
| 完整桌面回归 | 原始结果 250 通过、1 失败，失败点是宏编辑器点击后保留待提交值。宏编辑器单独复测 16 通过、0 失败，原始全套结果仍按当次记录。 |

实点与后台消息使用自有测试窗口验收。实体鼠标和键盘的完整录制链路，以及跨 DPI、多显示器环境，未纳入这份单文件版实测。
